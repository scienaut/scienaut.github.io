05 · Distributed loads — UDL & UVL

Both are optional. Add as many load regions as required. Positive Fy is downward in the side-view convention; negative Fy is upward. Fz is the orthogonal transverse direction.

Uniformly Distributed Load (UDL)

Constant force per unit length over a defined interval.

Benchmark: 500 mm span, 2 N/mm full-span UDL. Reactions: 500 N each; maximum moment: 62,500 N·mm; Ø30 mm steel shaft deflection: approximately 0.195 mm.

Uniformly Varying Load (UVL)

Linear variation between start and end intensities. Set one end to zero for a triangular load; non-zero end values give a trapezoidal or reverse-tapered distribution.

Start x (mm)End x (mm)Fy start (N/mm)Fy end (N/mm)Fz start (N/mm)Fz end (N/mm)

Benchmark: 500 mm span, triangular UVL increasing 0 → 4 N/mm. Resultant: 1,000 N at x = 333.33 mm; reactions: A = 333.33 N, B = 666.67 N; maximum bending moment ≈ 64,150 N·mm.

06 · Material properties

Data provenance: grade designations reference applicable ISO 683, BIS, ASTM / SAE and manufacturer specifications. Materials Project data is computational research data, not a certified design allowable. Elastic constants in the library are indicative reference values only. References and limitations

Material references: ISO 683 series, BIS IS 1570 / IS 2062 where applicable, ASTM A29/A29M, ASM / MatWeb property references, manufacturer datasheets and mill test certificates. Engineering methods: Shigley's Mechanical Engineering Design; ASME B106.1M may be relevant to transmission shafting. Verify current editions and applicability. No blanket standards compliance is claimed.

V1.0 uses linear-elastic Euler–Bernoulli beam assumptions, small deflections, point loads and two radial simple supports. It does not calculate bearing life, critical speed, dynamic response, gear forces, full fatigue life, notch sensitivity, residual/thermal stress or arbitrary 3D geometry. Verify all critical properties and results independently.
