# Engineering Tools

This folder contains the Engineering Tools hub linked from the main portfolio navigation.

## Pages
- `index.html` — calculator directory.
- `slider-crank/index.html` — self-contained slider-crank engineering calculator.
- `structural-member/index.html` — self-contained structural member calculator.

These are static browser pages suitable for GitHub Pages. No Python server or package installation is required to open the deployed HTML calculators.
