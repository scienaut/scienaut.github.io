1D Tolerance Stack-Up Analyzer

Build a signed linear dimensional chain and evaluate its functional limits using worst-case and statistical Root Sum Square (RSS) methods. Enter drawing deviations separately; statistical assumptions are never applied silently.

01 · Stack setup

Define the output equation through each component's contribution direction. For a clearance stack, additive dimensions increase clearance and subtractive dimensions reduce it.

02 · Component dimensions

Upper and lower deviations are signed offsets from nominal. Example: 25 +0.20 / −0.10 is entered as upper +0.20 and lower −0.10. Select + or − according to the dimensional chain equation.

04 · Standards guidance

Reference boundaries: ISO 286-1/-2 cover limits and fits for linear sizes; ISO 14405-1 addresses linear size specification; ISO 8015 defines fundamental GPS principles; ISO 2768-1 applies general tolerances when invoked by the drawing. ASME Y14.5 covers GD&T and drawing interpretation; it is not a universal dimensional tolerance table. This first release provides standards guidance and manual tolerance entry, not an embedded licensed tolerance database or automatic compliance certification. Verify the applicable edition and drawing requirements.
