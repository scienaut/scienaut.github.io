Engineering product data, organized around your BOM.

Scienaut Engineering PLM Solutions is a browser-based product lifecycle workspace for building and managing engineering item masters, multi-level bills of materials, revisions, and change history on your own Windows computer.

Runs locally on your PC. This portfolio page is informational; it does not host the PLM application online. The app uses a local browser interface, local API service, and SQLite database. There are no cloud accounts or multi-user access controls.

What you can do

A practical engineering data workspace with relationships kept between items, BOM occurrences, and revisions.

🧩 Product structure

Build multi-level assemblies and parts, reuse shared items, and inspect parent-child relationships.

📋 Excel-style BOM

Edit BOM rows and hierarchy levels, import spreadsheets with a preview, and export engineering registers to Excel.

🗺 BOM mind map

Explore product relationships in vertical or horizontal views with zoom, pan, item details, and links for repeated parts.

Compare revisions, review audit history, prepare and release working revisions, and track scoped change notices.

Create and restore verified SQLite backups. Your product data remains on the computer where you run the app.

How the local application works

The interface opens in your browser, while its API and database run on your own PC. The first launch installs the project's Python and JavaScript dependencies; after setup, the launcher starts the local services and opens the workspace.

Operating system
Windows 10 or 11
Required tools
Python with the Windows py launcher, plus Node.js and npm
First setup
Internet connection required to install dependencies
Data location
local_data/Database/engineering_plm.sqlite3 inside the extracted app folder

Download and start on Windows

  1. Install prerequisites. Install Python 3 and Node.js (LTS), including npm. Open PowerShell and check that py --version and npm --version both work.
  2. Download and extract. Use the Download Windows package button above. Extract the complete ZIP into a writable folder, for example Documents\Scienaut-PLM. Do not run the app from inside the ZIP preview.
  3. Launch the workspace. Double-click Open_Engineering_PLM.vbs for the one-click launcher. The first run creates the Python environment, installs required packages, prepares the database, and installs frontend packages. This may take a few minutes.
  4. Use the browser app. The launcher opens the local application, normally at http://127.0.0.1:5173. If that port is busy, the launcher chooses another available port and opens it.
  5. Keep the extracted folder. The database and app files live there. Use the app's Backup & restore feature before moving, deleting, or replacing the folder.
Need to see startup messages or stop the server? Run start_application.bat directly to use a visible console. Keep that window open while using the app; press Ctrl+C in it to stop the local services. The VBS launcher hides the console.

Good practice and warnings

  • Keep one extracted copy as the active workspace and make regular backups to another drive.
  • Do not delete local_data or overwrite the SQLite database unless you have a verified backup.
  • The application is designed for one local computer. It does not provide user accounts, access permissions, or shared online collaboration.
  • The first run downloads dependencies from package registries. After setup, the application services run on your computer; do not expose the local API port to a public network.
  • Demo mass and cost values are examples, not engineering reference data. Check engineering entries before using them for manufacturing or release decisions.
  • Releasing revisions locks released data. Follow the app's child-before-parent release order and use a new working revision for changes.
